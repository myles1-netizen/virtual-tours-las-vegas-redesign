## Purpose
This is a help page explaining how to navigate the embedded 360/Matterport tours across devices, NOT a sitemap page (despite the URL slug).

## Body Content
Explains the tour viewer "works responsively on touch screens like Phones, Tablets along with Laptop and Desktop Computers."

**Touch device controls:**
- Vertical finger movements adjust viewing angle
- Two-finger pinching zooms in/out
- Circular motions rotate the property view

**Desktop/laptop controls:**
- Mouse movements mirror touch gestures
- Mouse wheel zooms
- Keyboard directional arrows navigate
